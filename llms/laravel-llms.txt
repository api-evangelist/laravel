# Laravel

> Laravel builds the Laravel PHP framework and a suite of commercial developer infrastructure products.
> Two of them — Laravel Forge (server provisioning and application deployment) and Laravel Cloud (a fully
> managed PaaS) — publish complete OpenAPI 3.1 descriptions and a JSON:API-flavoured REST surface.
> Envoyer publishes a documented REST API without a machine-readable description. Laravel also ships
> Laravel Boost, a first-party MCP server and Agent Skills bundle for AI coding agents.
> This file is generated by the API Evangelist enrichment pipeline. Laravel's own llms.txt files are
> saved verbatim alongside it.

## APIs

- [Laravel Forge API](https://forge.laravel.com/docs/api-reference/introduction): current v2 API. Base URL https://forge.laravel.com/api. 154 paths, 273 operations, bearer token + OAuth 2.0 authorization code with 62 scopes.
- [Laravel Forge API (legacy v1)](https://forge.laravel.com/api-documentation): deprecated, discontinuation announced for 2026-07-31. Base URL https://forge.laravel.com/api/v1.
- [Laravel Cloud API](https://cloud.laravel.com/docs/api/authentication): base URL https://cloud.laravel.com/api. 61 paths, 104 operations, bearer token.
- [Envoyer API](https://envoyer.io/api-documentation): base URL https://envoyer.io/api. Bearer API key, no OpenAPI published.

## API conventions

- [Introduction](https://forge.laravel.com/docs/api-reference/introduction): auth, headers, status codes
- [Pagination](https://forge.laravel.com/docs/api-reference/pagination): cursor pagination via page[size] and page[cursor]
- [Rate Limiting](https://forge.laravel.com/docs/api-reference/rate-limiting): 60 requests/minute, X-RateLimit-* headers
- [Filtering & Sorting](https://forge.laravel.com/docs/api-reference/filtering): filter[field] and sort=-field
- [Relationships & Includes](https://forge.laravel.com/docs/api-reference/relationships): include=relationship
